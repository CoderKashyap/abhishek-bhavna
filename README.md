# SelfInvitation — Abhishek & Bhavna

Soft-romantic wedding invitation webpage (Vite + React + TypeScript).

## Local preview (Windows)

From `C:\Users\Acer\OneDrive\Desktop\SelfInvitation`:

```bat
npm install
npm run dev
```

Open the URL Vite prints (usually `http://127.0.0.1:5173/`).

## Build

```bat
npm run build
npm run preview
```
